# LispBMで車速をCANに定期送信する

VESCがモーター回転数から換算した車速を、約20 ms間隔でCANに送信します。VESC ToolからLispBMスクリプトを保存すると、PCを接続しなくてもVESCの起動時から送信できます。

標準のCAN Status 1に含まれるのは電気回転数（ERPM）です。車速に換算した値を定期送信する選択項目は、確認した公式標準実装にはありません。この手順では独自のCANフレームを追加します。[根拠: CAN送信処理](https://github.com/vedderb/bldc/blob/21e66bb9efb41322c84f34c1db03a71ffeb7d8a1/comm/comm_can.c#L1135-L1188)

初回は「1. 設定と既存コードを保存する」から「7. 再起動して自動送信を確認する」まで順に実施してください。送信形式、停止・復元、トラブル対応は後から参照できます。

**検証状況: 公式ソースを確認して作成した手順です。実機での設定操作、LispBM実行、CAN受信、周期測定は未実施です。**

## 対象と前提条件

- LispBMに対応するVESCとPC版VESC Toolを使用します。今回使う`get-speed`、`can-send-eid`、`loopwhile`は、公式資料ではFW 6.00以降に対応しています。機種やファームウェアの構成によってLispBM自体の有無が異なります。
- VESCが妥当なモーター回転数を取得できる構成が前提です。他励直流・ブラシ付きDCモーターでは、標準の回転数取得と換算がその構成で機能するか先に確認してください。このスクリプトは回転センサーの代わりにはなりません。
- CANモニターと、同じバス上に少なくとも1台のACKを返せるCANノードを用意します。受信器をlisten-onlyにしただけの構成では、ACKが得られない場合があります。ビットレートと終端抵抗は使用するバスに合わせます。
- 初回の回転確認は、車両が動き出さず、回転部分に触れずに済む状態で実施します。

[根拠: LispBMの機能・対応版](https://github.com/vedderb/bldc/blob/21e66bb9efb41322c84f34c1db03a71ffeb7d8a1/lispBM/README.md)

## 今回追加するCANフレーム

この形式は本手順書で決めた独自形式です。VESC標準の車速メッセージではありません。受信側にも同じIDとデータ形式を設定します。

| 項目 | 値 |
|---|---|
| CAN形式 | Classical CAN、29 bit拡張ID |
| CAN ID | `0x10000107`（仮の割り当て） |
| DLC（データ長） | 4バイト |
| データ型 | 符号付き32 bit整数、2の補数 |
| バイト順 | ビッグエンディアン。上位バイトから送信 |
| スケール | 1カウント = 0.01 km/h |
| オフセット | 0 |
| 車速への換算 | 受信整数 ÷ 100 = km/h |
| 送信間隔 | 約20 ms（目標50 Hz） |
| ビットレート | 既存のCANバスに合わせる |

このIDを使用する前に、バス全体のID割り当てを確認します。複数のVESCから送る場合は、それぞれ異なるIDを割り当ててください。コードのID末尾の`u32`は、LispBMで32 bit符号なし整数として扱うための型指定です。

## 1. 設定と既存コードを保存する

1. VESC Toolを起動し、対象のVESCに接続します。CAN転送接続を使う場合は、接続先の機器とController IDを確認します。
2. Motor設定とApp設定をVESCから読み出し、それぞれファイルに保存します。
3. VESCの機種、ファームウェア版、VESC Toolの版、現在のCANビットレートを記録します。
4. **VESC Dev Tools → LispBM** を開き、**Read** で既存コードを読み出してPCに保存します。画面名はVESC Toolの版によって異なる場合があります。

既存のLispBMアプリやVESC Packageがある場合は、単独のサンプルをStream／Uploadしないでください。Streamは実行中のLispBM処理を置き換え、Uploadは保存済みコードも置き換えるため、既存アプリの機能が止まります。既存コードの実行構造に合わせ、送信処理を組み込んでから確認します。本サンプルの無限ループを既存コードの先頭に貼ると、後続の処理に到達しません。

[根拠: VESC ToolのLispBM読み出し・アップロード処理](https://github.com/vedderb/vesc_tool/blob/85fc40852541a0cc1f8b6339ff98b1f65a48ed93/pages/pagelisp.cpp)

## 2. 車速換算とCAN通信を設定する

**Motor Settings → Additional Info → Setup** で、次の値を設定します。

| 設定 | 入力する値 | 例 |
|---|---|---|
| Motor Poles | モーターの磁極数。極対数の2倍 | 7極対なら14 |
| Gear Ratio | モーター回転数 ÷ 車輪回転数 | モーター3回転で車輪1回転なら3 |
| Wheel Diameter | タイヤ外径。画面に表示された単位に合わせる | 外径500 mmなら、mm表示時は500、m表示時は0.5 |

設定後に **Write Motor Configuration** で保存します。例の値を実機にそのまま入力せず、モーター仕様と実際の伝達比・タイヤ寸法を使用してください。

通常の回転数換算では、内部で次の計算を行います。`get-speed`の単位はm/sです。外部車速センサーや車速上書きを使用する構成では、そちらの値が使われる場合があります。

```text
機械回転数[rpm] = ERPM ÷ (Motor Poles ÷ 2)
車速[m/s] = 機械回転数 ÷ 60 × π × タイヤ外径[m] ÷ Gear Ratio
車速[km/h] = 車速[m/s] × 3.6
```

**App Settings → General** のCAN設定では、CAN Modeを **VESC** とし、ビットレートを既存バスに合わせます。変更した場合はApp設定を書き込みます。接続先全体を同じビットレートにする必要があります。

標準の「CAN Status Rate」は、今回のLispBM送信周期を変更しません。今回の送信だけのために標準Statusメッセージを有効化する必要もありません。

[根拠: 車速換算](https://github.com/vedderb/bldc/blob/21e66bb9efb41322c84f34c1db03a71ffeb7d8a1/motor/mc_interface.c#L1536-L1554)、[Setup画面](https://github.com/vedderb/vesc_tool/blob/85fc40852541a0cc1f8b6339ff98b1f65a48ed93/pages/pagemotorinfo.cpp)

## 3. REPLで車速とデータの格納形式を確認する

LispBM画面のREPL（式を入力して結果を確認する欄）で、次を実行します。

```lisp
(* (get-speed) 3.6)
```

結果はkm/hです。停止時にほぼ0になり、安全に車輪を回したときに妥当な値へ変化することを確認します。停止したまま0が出るだけでは、回転数取得が機能しているとは判断できません。別の測定手段と照合してから次に進んでください。

既存アプリがないことを確認した構成では、[格納形式のテスト](../examples/speed-payload-self-test.lisp)もREPLで実行します。複数の式を受け付けない版では、上から1式ずつ入力します。最後の式の期待結果は`t`です。このテストは、−10 m/sを−36 km/hへ換算し、`FF FF F1 F0`として格納できるかを確認します。モーター指令やCAN送信は行いません。

## 4. スクリプトをStreamで一時実行する

既存アプリがない構成向けの手順です。[送信スクリプト](../examples/periodic-speed-can.lisp)を開き、未使用のCAN IDへ変更したうえで、LispBMエディターに読み込みます。

```lisp
(define speed-data (bufcreate 4))

(loopwhile t
  (progn
    ; m/s * 3.6 * 100 = 0.01 km/h units.
    (bufset-i32 speed-data 0 (* (get-speed) 360.0))
    (can-send-eid 0x10000107u32 speed-data)
    (sleep 0.02)))
```

**Stream** を押して一時実行し、エラーが出ていないことを確認します。Streamはフラッシュに保存しないため、今回のコードは電源を切ると失われます。停止していた既存の保存済みアプリがあれば、次回起動時にはそちらが再び動くため、単独サンプルへの置き換えには使わないでください。

`sleep 0.02`は、送信処理後に20 ms待つ指定です。処理時間、スケジューリング、CANの混雑が加わるため、厳密な20 ms固定にはなりません。送信失敗時の再送・通知は、このサンプルでは追加していません。受信側では更新が止まった場合を検出します。

[根拠: CAN送信関数](https://github.com/vedderb/bldc/blob/21e66bb9efb41322c84f34c1db03a71ffeb7d8a1/lispBM/README.md#can-send-eid)、[バッファのバイト順](https://github.com/vedderb/bldc/blob/21e66bb9efb41322c84f34c1db03a71ffeb7d8a1/lispBM/lispBM/doc/arrayref.md#writing-to-buffers)

## 5. CANモニターで値と周期を確認する

CANモニターのビットレートを合わせ、拡張ID `0x10000107`、DLC 4で絞り込みます。IDを変更した場合は、その値に合わせてください。

| 入力車速 | 送信整数 | データ[HEX] | 受信側の解釈 |
|---|---:|---|---|
| 0 m/s | 0 | `00 00 00 00` | 0.00 km/h |
| 10 m/s | 3600 | `00 00 0E 10` | 36.00 km/h |
| −10 m/s | −3600 | `FF FF F1 F0` | −36.00 km/h |

表はデータ形式の確認用であり、実車をこの速度まで加速する指示ではありません。逆転時の符号はモーターの方向設定にも依存します。

1. 受信フレームが拡張ID・4バイトであることを確認します。
2. 受信側で符号付き32 bit・ビッグエンディアンとして読み、100で割ります。
3. 車輪停止時と低速回転時の値を、手順3の車速表示や別の測定手段と照合します。
4. 連続する受信タイムスタンプの差を確認し、約20 ms間隔になっているか測定します。平均値だけでなく、最大間隔と受信抜けも記録します。

この4バイトには時刻や有効フラグを含めていません。受信側で更新タイムアウトを設定し、通信が止まったときに最後の車速を現在値として表示し続けないようにします。タイムアウト値は実測した最大間隔と表示要件から決めてください。回転数が誤っている場合は、送信が続いていても車速は誤った値になります。

## 6. UploadでVESCに保存する

一時実行の確認後、送信スクリプトをPCにも保存し、**Upload** を押します。書き込み完了後に実行状態を確認し、停止している場合は **Run** を押します。

UploadしたコードはVESCのフラッシュに保存され、起動時に自動実行されます。別途「起動時に実行」の設定を追加する手順は、確認した版にはありません。

[根拠: Upload・Stream・Eraseの仕様](https://github.com/vedderb/vesc_tool/blob/85fc40852541a0cc1f8b6339ff98b1f65a48ed93/pages/pagelisp.ui#L31-L68)

## 7. 再起動して自動送信を確認する

1. VESCを安全に停止し、電源を切ります。
2. CANモニターを受信できる状態にして、VESCを再起動します。
3. VESC Toolを接続せずに、車速フレームが送られることを確認します。
4. 車速と受信間隔を再確認し、使用した版と結果を記録します。

記録項目は、VESC機種、FW版、VESC Tool版、モーター方式、磁極数、減速比、タイヤ径、CANビットレート、送信ID、受信周期の平均・最大、自動起動結果です。このリポジトリでは、実測記録はまだありません。

## 送信を止める・以前の状態に戻す

- 一時停止する場合は、LispBM画面で **Stop** を押します。保存済みコードは残るため、次回起動時には再実行されます。
- この送信専用スクリプトの保存と自動起動を解除する場合は、**Erase** を使います。既存アプリと統合している場合はアプリ全体を消さず、送信処理を除いたコードに戻します。
- 以前のLispBMアプリへ戻す場合は、バックアップした元コードをUploadします。VESC Packageから導入したアプリは、そのパッケージの復元手順に従います。
- 換算値やCAN設定も変更した場合は、必要に応じてMotor設定・App設定のバックアップを復元します。

## 困ったときに確認する場所

| 症状 | 確認すること |
|---|---|
| LispBM画面や関数が使えない | 機種とFWのLispBM対応。対応確認のためだけに安易にFWを更新しない |
| 回転しても車速が0 | VESC自体の回転数取得、モーター方式、外部車速の設定 |
| 車速が一定倍率でずれる | 磁極数と極対数の取り違え、減速比の向き、タイヤ径の単位 |
| CANを受信できない | 拡張IDフィルター、ビットレート、配線、終端、ACK、LispBMエラー |
| 負の速度が大きな正数になる | 受信側が符号なし整数として解釈していないか |
| 再起動すると送信されない | Streamだけで終わっていないか、Uploadの完了、起動時のLispBMエラー |
| 約20 msより大幅に遅い・受信が抜ける | バス負荷、送信エラー、他のLispBM処理、受信器の処理や記録の遅延 |

解決しない場合は[Issues](https://github.com/e-lab-pius-project/vesc-setup-guides/issues)に、使用した版、該当手順、エラー文、個人情報を除いたCANログを添えて報告してください。

## 用語

| 用語 | 意味 |
|---|---|
| ERPM | 電気回転数。通常の回転数換算では極対数で割ると機械回転数になる |
| LispBM | VESC内部でスクリプトを実行する仕組み |
| REPL | 式を入力して実行結果を確認する対話欄 |
| 拡張ID | 29 bitのCAN識別子 |
| DLC | この手順ではCANフレームのデータ長 |
| ビッグエンディアン | 多バイト値の上位バイトを先に並べる順序 |
